
# PicoPC SDK

The official SDK for PicoPC


## Authors

- [@rocketLover11](https://www.github.com/rocketLover11)


## Installation

Put the SDK in your project's Cargo.toml

```toml
  [dependencies]
  picopc-sdk = "0.1.0"
```
